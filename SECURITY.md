# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in QR Password Fill, please report it responsibly.

**Do NOT open a public issue.**

Instead, please email: **security@johannesriedl.com**

Include:
- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

## Response Timeline

- **Acknowledgement:** Within 48 hours
- **Assessment:** Within 7 days
- **Fix/Disclosure:** Coordinated with reporter

## Scope

This policy covers:
- The Chrome extension (`extension/`)
- The standalone QR generator (`qr-generator/`)

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | ✅        |
