Passwords that never touch the network

A browser extension that fills login credentials by scanning QR codes from your password manager. 100% offline. Zero data collection. Air-gapped security.

⬇ Download Extension 📂 View Source

How It Works

📱
1

Display the QR Code

Open your password manager and show the QR code for the credential you need. Works with any manager that supports QR export.

📷
2

Scan with the Extension

Click the extension icon in your browser. It activates your webcam, reads the QR code, and immediately stops the camera.

✅
3

Password Filled

Your username and password are instantly filled into the login form. Nothing is stored. Nothing is sent anywhere. Done.

Why QR Password Extension?

🔒

Air-Gapped Security

Your credentials travel through light, not the internet. The QR code goes from your phone screen to your webcam — never touching a server.

📡

100% Offline

No accounts to create. No cloud sync. No servers. The extension works entirely in your browser with zero network requests.

🕵️

Zero Tracking

No analytics. No telemetry. No data collection of any kind. We don't even have a server to send data to.

🔓

Open Source (MIT)

Every line of code is public. Audit it, fork it, improve it. Full transparency — the way security software should be.

🔗

Works With Any Password Manager

KeePassXC, Bitwarden, 1Password — if it can display a QR code with credentials, this extension can read it.

🛠️

Bonus: Offline QR Generator

Includes a standalone HTML page to generate QR codes from credentials. Works completely offline — just open the file in any browser.

🛡️ Our Privacy Promise

This extension was built with one principle: your credentials are yours alone.

  • No data ever leaves your browser
  • Camera activates only when you click — stops immediately after scan
  • No persistent storage of credentials
  • No analytics, cookies, or tracking of any kind
  • No external scripts, CDNs, or third-party code
  • Fully auditable open-source codebase
